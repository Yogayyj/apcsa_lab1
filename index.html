Random numbers

Math.random()
// double: 0.0 ≤ value < 1.0

(int) (Math.random() * count) + 1
// integer: 1 through count

Multiply first, cast to int, then add 1. For count = 5, possible numbers are 1, 2, 3, 4, or 5.
