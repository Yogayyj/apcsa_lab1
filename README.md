# Fashion Item Java Lab

A single-page AP CSA classroom lab for practicing:
- creating objects with `new`
- constructor parameters vs arguments
- instance method calls
- static method calls

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` (README is optional).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.

## Java execution
GitHub Pages is static hosting and cannot compile Java server-side. The site therefore has two modes:
- **Check Answer**: works immediately in the browser and checks the required Java structures.
- **Run Code**: requires a Judge0-compatible submissions endpoint. Enter the endpoint in the Java Runner box.

For a classroom deployment, use an endpoint you control rather than embedding private API keys in GitHub Pages.
